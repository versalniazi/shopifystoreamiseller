## General SEO Recommendations

### Open Graph Tags

Apply site-wide via the theme's `<head>` include, with page-specific overrides for title/description/image:

- `og:site_name` → `Hire Nestt`
- `og:type` → `website` for all standard pages; `product` for the 8 product pages (paired with the Product schema below); `article` for individual blog posts
- `og:url` → canonical URL of the current page
- `og:image` → one image per page at **1200×630px**, Ink Navy (`#0F172A`) background with the Hire Nestt wordmark and the page's H1 or product title overlaid in white/teal — a single reusable template with the title text swapped per page keeps this cheap to produce and visually consistent. Product pages can use a template that also shows the price and package name.
- `og:title` → same as Title Tag (trim if the template adds a suffix)
- `og:description` → same as Meta Description

### Twitter Card

- `twitter:card` → `summary_large_image`
- `twitter:site` → `@hirenestt` (placeholder — replace with the real handle before launch, or omit the tag entirely if no account exists yet)
- `twitter:title` / `twitter:description` → mirror `og:title` / `og:description`
- `twitter:image` → mirror `og:image`

### Schema.org Structured Data

- **Organization schema — Homepage.** `@type: Organization`, `name: "Hire Nestt Limited"`, `url`, `logo` (theme logo asset), `email: "hirenest56@gmail.com"`, `sameAs: [social profile URLs]`. Place as JSON-LD in the homepage template only (or site-wide via theme.liquid if preferred, since Organization is a site-level entity).
- **Product schema — all 8 product pages.** `@type: Product`, `name`, `description`, `sku`, `brand: { "@type": "Brand", "name": "Hire Nestt Limited" }`, `offers: { "@type": "Offer", "priceCurrency": "USD", "price": "<variant price>", "availability": "https://schema.org/InStock", "url": "<canonical product URL>" }`. Since these are services rather than physical goods, consider `Service` schema as an alternative/addition where a theme app or reviewer flags Product schema as a poor fit for non-shippable items — Shopify's native product schema output already defaults to `Product`, which is acceptable for Merchant Center and rich results as long as `shippingDetails` is omitted or marked not applicable.
- **FAQPage schema — FAQs page only.** `@type: FAQPage` with a `mainEntity` array of `Question`/`Answer` pairs matching the on-page accordion content exactly (structured data must mirror visible content).
- **BlogPosting schema — every blog article.** `@type: BlogPosting`, `headline`, `author: { "@type": "Organization", "name": "Hire Nestt Limited" }`, `datePublished`, `dateModified`, `image`, `publisher` (with logo).
- **BreadcrumbList schema — all pages.** `@type: BreadcrumbList` reflecting the actual navigation path, e.g. Home > Packages > Job Hunter Bundle, or Home > Blog > [Article Title]. Implement once as a reusable Liquid snippet that reads the current page's position in `02-website-structure.md`'s sitemap.

### Internal Linking Suggestions

1. **Resume Writing page** → links to the **Professional Resume** product and to the ATS Optimization explanation section on **Home**.
2. **Cover Letter page** → links to the **Resume + Cover Letter** product and to the **Professional Resume** product as the base offering.
3. **LinkedIn Optimization (service) page** → links to the **LinkedIn Optimization** product and to the **Job Hunter Bundle** as the multi-service upgrade path.
4. **Packages collection** → links out to all 8 individual product pages, and back to the pricing/packages preview section on **Home**.
5. **Industries page** → each industry anchor links to the most relevant package (e.g., the "Executives" section links to **Executive Career Package**; the "Graduates" section links to **Entry-Level Graduate Package**) and to **Success Stories**.
6. **FAQs page** → links out to **Refund Policy**, **Revision Policy**, and **Shipping & Delivery (Digital Delivery)** for questions that need full policy detail rather than a short answer.
7. **Blog articles** → each article links back to the most topically relevant product/service page (e.g., an ATS-focused article links to **Professional Resume** and **Starter Career Package**) and to the **Packages collection** as a general next step.
8. **About Us page** → links to **Success Stories** (proof of approach) and to **Contact** (path to reach the team directly).
